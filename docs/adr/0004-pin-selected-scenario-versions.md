# Pin the selected scenario version

A group must keep the scenario version it explicitly selected even when another group reparses the same logical scenario. We chose immutable published versions and explicit, coherent switching of text/images/maps and character/NPC source evidence rather than automatic following of latest, because source drift changes rulings and rollback evidence without a game decision. This accepts version-storage and migration work; missing historical evidence must not be represented as proof that a game used latest. Legacy versions are bound only from reliable evidence; otherwise stored history stays readable with unconfirmed/unavailable source assets rather than a guessed latest binding. Current combat, checks and Luck finish before switching versions; continuing obligations need explicit compatibility handling. The detailed future-obligation policy remains subject to the ongoing interview.
