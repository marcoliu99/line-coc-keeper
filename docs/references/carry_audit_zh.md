# 隨身物、購買與敘事合理性

[English](carry_audit.md)

## 目前實作

`Character.carried_items` 與武器／彈藥記錄已確立持有物；`Character.cash_balances` 及 `GroupState.commerce` 現已實作確認餘額、報價與收據。舊說法「購買完全靠 prompt、沒有現金帳本」已過時。

## 判斷邊界

合理日常小物直接允許，避免遊戲變審查；具劇情、戰鬥、稀有、管制或高價影響物品須劇本／正典依據，考慮年代、地域、職業／來源與負擔能力。不能籠統宣稱 1920 年代沒有所有無線電或半自動武器，可得性依實際物品與背景。

## 購買順序

先完成移動並確立有依據商店／庫存，再取得物品。生活水準模式記錄信用評級負擔判斷與收據；現金模式須確認幣別／資金並明確確認報價。扣款、背包與收據原子結算；地圖座標可選。後端查識別／一致性，AI 仍裁定敘事到店與庫存。

## 敘事與限制

本回合購買要描述成現在買入，最終背包不能證明原本持有；報價不是付款。玩家說一直帶著武器也不能默默白送；通用結構化合法性／年代驗證與自動變賣資產尚未實作。
