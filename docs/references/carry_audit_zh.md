# 隨身物、購買與敘事合理性

[English](carry_audit.md)

## 目前實作

`Character.carried_items` 與武器／彈藥記錄已確立持有物。舊存檔中的 `Character.cash_balances` 與 `GroupState.commerce` 仍可讀取，但目前沒有啟用中的現金帳本、報價或購買收據流程。

## 判斷邊界

合理日常小物直接允許，避免遊戲變審查；具劇情、戰鬥、稀有、管制或高價影響物品須劇本／正典依據，考慮年代、地域、職業／來源與負擔能力。不能籠統宣稱 1920 年代沒有所有無線電或半自動武器，可得性依實際物品與背景。

## 購買順序

先處理前往店家的移動，確認合理的販售來源與商品供應，再取得物品。守密人依信用評級與角色處境裁定負擔能力，不計算現金扣款。購買在劇情中成立後，值得長期記錄的物品以 `add_carried_item` 登記。目前沒有報價、付款確認或原子交易工具。

## 敘事與限制

本回合購買要描述成現在買入，最終背包不能證明原本持有或已付款。玩家說一直帶著武器也不能默默白送；通用結構化合法性／年代驗證、現金記帳與自動變賣資產尚未實作。
