# `role_` 上傳的角色卡製作模板

[English](role_card_template.md)

此格式用於確定性 `.txt`／`.md` 匯入。中文段落標題是解析器鍵值，保留 `【...】` 拼法。
一位調查員一個檔案，例如 `role_investigator.md`。上傳後查看 `/coc pregens`，再用
`/coc usepregen NUMBER` 認領。這不是劇本模板 records JSON 格式。

## 欄位與來源忠實度

已對照使用者提供的 *Doors to Darkness Pre-Generated Characters*（11 頁 PDF：
封面及十位調查員）。外貌、性格、信念、關係、地點、珍藏與背景都是開放文字。
原稿空白讓玩家自行個人化，不授權解析器編造內容。

- 屬性／技能以 `標籤: 數值` 表達，不用將困難／極難值另建技能。Luck 空白保持空白，
  沿用玩家擲 Luck 流程；保留實際印刷值，不猜值。
- 姓名／職業之外的識別欄位是描述備註。年齡、性別、出生地不是固定枚舉，複製這些
  不代表自動實作年齡調整；原文名與譯名要能區分。
- 描述段落允許多段、列表、標點、數字與混合語言名稱；不把句子轉成布林、枚舉或分數。
  重複名稱／關係不授權新建 NPC。
- 描述空白段落在 `extra_fields` 留空字串；缺少段落則維持不存在。兩者都不代表角色
  沒有信念、關係或物品。非空自訂段落也保留。
- `【關鍵背景連結】` 只用於明確星號連結，不將珍藏或重要人物自動升格為此機制角色。
- 描述 extras 與背景可能在公開角色卡顯示。私人動機放 `【角色扮演動機】`，遵守現有
  隱私政策；不要假設普通 `【玩家筆記】` 是私密。KP／系統仍依權限存取。
- `【財務原文備註】` 以文字保留現金、債務、資產或不確定幣別，不建立交易或帳本餘額。
  現行購買流程由 KP 另行確認幣別及餘額，才可精確扣款。
- `【原卡衍生數值備註】` 保留印刷 HP／MP／SAN／MOV／DB／Build 供核對。這是描述證據，
  不是覆寫：手動解析仍由基本屬性推導初始機制。開局前處理差異，不能認為改備註已改狀態。
- 武器區除既有武器／彈藥分類外，完整原始描述也保留於 `extra_fields`。不能因抽彈藥而
  丟失傷害、射程、特殊效果與限制；這不新增自動特殊能力結算。裝備一行一項，未提供則留白。

下方技能預設對應目前基礎技能模板。預製卡請以實際印刷值替換，包含閃避與語言專長。
每個專長用不同技能名，例如攝影或地質學。

武器語法示例（改成實際來源，不預設贈送）：

```text
【武器】
武器名稱
技能：來源技能與百分比
傷害：來源傷害骰式
彈容量：來源明示容量
射程與限制：完整描述條件
```

只複製下方模板。空白描述可留給玩家填寫，原稿缺少時也可省略；
不能只因欄位存在就填入未知事實。
