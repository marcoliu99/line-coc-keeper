# 劇本模板參照審查

[English](scenario_template_reference_review.md)

## 來源範圍

短劇本審查使用提供的 The Haunting 刪節 PDF（27 頁）、Dead Boarder（32 頁）、The Lightless Beacon（43 頁）；角色卡參照 Doors to Darkness Pre-Generated Characters（11 頁）。長團比較使用 Masks of Nyarlathotep、Horror on the Orient Express 官方參考／介紹，未閱讀完整商業長團。

## 設計影響

組織語意記錄，不固定逐頁翻譯；保留跨頁觸發／後果、敵人規則、可見性、識別／別名、縮放、規則模式與前提連結。劇本出版版本與 CoC／Pulp 模式是不同識別，章節及依賴展開仍須保留存取邊界。

## 製作產物

使用本 reference 目錄的外部中文製作指南與角色卡模板；劇本工作簿用 schema v3 hash、精確 spans 與欄位引句，role_ 卡用解析器指定標題。描述空白供玩家補充，不授權解析猜測；Luck 空白保持空白。
