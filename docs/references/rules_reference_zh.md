# 已實作機制與規則缺口

[English](rules_reference.md)

## 依據與範圍

這是本庫實作參考，不是重新核對完整 CoC 規則書；支援機制以 `app/dice.py`、`app/combat.py`、`app/luck.py` 與回歸測試為依據，劇本內容由劇本決定。

## 檢定與幸運

支援 d100 等級、獎懲骰、一般／困難／極難要求、SAN 損失骰式、擁有者觸發 pending 與可選群組 autoroll；必須達要求難度，不是有任意成功等級就過。Luck 只要合法、有效且付得起就提供，SAN 不適用；預製 Luck 空白由本人明確擲骰。

## 戰鬥

支援 DEX 順位、不同 NPC 戰鬥卡、護甲、攻擊、能力、回合／輪次效果、傷害加值與穿刺計算；近戰閃避同成功等級勝，反擊須更高；遠程防禦另有規則。原始／最終傷害工具避免重扣護甲，重傷檢定遵守 pending／autoroll 所有權。

## 仍有缺口

不宣稱有完整通用雙玩家對抗協調器、組合技能單骰工具、擒抱／繳械 Build 引擎或完整自動奇襲／圍攻引擎。難度選擇、調查節奏與許多可得性判斷仍依 Keeper；支援特殊能力不代表所有出版法術都已實作。

## 物品與金錢

敘事政策可允許日常小物，重要取得须有依據；購買現支援生活水準收據或確認現金報價、原子扣款／取得，不是通用經濟模擬或自動變賣資產系統。
