# 敘事節奏與 NPC 隊友

[English](gameplay_style.md)

## NPC 知識

隊友只知道親眼所見、場內被告知、自身有依據行動取得或公開線索合理推論的內容；可猜錯、有偏見、害怕或不耐。隊友身分不給 Keeper 秘密或自動最佳戰術。

## 行動與加入

每位隊友有劇本支持的參與理由；依劇本初始組隊前提，不編造延遲登場。隊友可做有限且有動機行動，但資訊仍遵守正常存取、時間、反應與檢定；玩家仍是主要決策者。

## 檢定

NPC 檢定用系統權威工具；玩家檢定通常等本人按鈕／命令，除非群組 autoroll 適用，多選一仍由玩家明確選擇；不可敘述未擲出的玩家結果。

## 鏡頭與收尾

交代地點、時間、在場者與目前壓力，最多一兩位相關隊友簡短反應後把場面交回玩家；畫面外行動不能無前提成本就交付重大線索，在玩家能行動或說話的具體點收尾。

## 正典與失敗

以已建立後果製造張力，不能新增無依據敵人或房間；有依據時失敗可改變時間、代價、傷勢或 NPC 反應，不授權改寫劇本。敘事政策由 prompt 驅動，不是完整確定性故事驗證器。
