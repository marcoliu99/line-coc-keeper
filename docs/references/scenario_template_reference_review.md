# Scenario-template reference review

[繁體中文](scenario_template_reference_review_zh.md)

## Source scope

Short-scenario review used the user-provided PDFs The Haunting (trimmed, 27 pages), Dead Boarder (32 pages) and The Lightless Beacon (43 pages). Role-card review used Doors to Darkness Pre-Generated Characters (11 pages). Long-campaign comparison used official reference/introductory material for Masks of Nyarlathotep and Horror on the Orient Express; it did not read the complete commercial campaigns.

## Design implications

Organize semantic records, not fixed page translations. Preserve cross-page triggers and consequences, enemy rules, visibility, identities/aliases, scaling, rule modes and prerequisite links. Scenario edition and CoC/Pulp rules mode are separate identities. Chapters and dependency expansion must retain access boundaries.

## Authoring artifacts

Use the external Chinese preparation guide and role-card template in this reference directory. Scenario workbooks use schema v3 hashes, exact spans and field-level quotes; role_ cards use parser-specific section labels. Blank descriptive fields invite player completion, not extraction guesses; blank Luck stays blank.
