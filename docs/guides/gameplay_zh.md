# 遊戲流程

[English](gameplay.md)

## 準備遊戲

上傳劇本 PDF 或透過 /coc help 選劇本庫；角色卡用 role_ 文字／Markdown，上述外部中文劇本工作簿另走 template export／import／preview／approve／use。來源／章節變更可使模板失效。

## 角色與開場

劇本有調查員時用 /coc pregens、/coc usepregen；否則可 /coc pc 或 /coc create 分配技能。保留卡面可驗證 Luck，空白由本人 /coc luck roll；讀不到的核心屬性须更正後才能認領該卡。就緒後 /coc start 使用劇本開場或生成有依據後備；start 前一般文字不推進遊戲。

## 行動與檢定

用一般訊息描述行動；Keeper 通常先登記檢定，本人以按鈕或 /coc check 擲骰。任何玩家可切換群組 /coc autoroll on|off，只影響新檢定；多選一防禦需明確選擇。合法、付得起且有效的 Luck 升級不限差一點成功，/coc luck skip 放棄；敘事失敗不重骰已結算骰子。

## 戰鬥、地圖與隱私

戰鬥用 DEX 順位、獨立敵人與正式傷害／效果；/coc combat status 看順位，/coc away、/coc back 管理暫離。地圖可選，/coc where、/coc enter、/coc leavemap 操作支援地圖；無地圖時移動仍依劇本。私人手稿／目標只傳授權對象，需私人資訊時請允許 DM。

## 購買與更正

先抵達有依據商店再買；生活水準購買記錄取得，現金購買須確認報價且帳上資金足夠。/coc purchases 看餘額／報價／收據，/coc purchase ID 確認付款。/coc correct 是遊戲外提報，須目前時間線訊息回條，提報本身不施加機制 hold；KP 可核准、駁回或指定 hold 範圍。

## Help 與管理

Help 按鈕可執行命令，必要時使用表單／清單；/coc sheet、/coc status 看狀態。KP Assistant 是獨立 OOC agent，授權 /coc sudo 可代允許的玩家操作。Checkpoint 還原建立隔離時間線；/coc end 結束、/coc newgame 重設，可重用手動角色資產依持久政策保留。精確權限與語法見命令參考。
