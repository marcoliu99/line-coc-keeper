# Two-phase image-grounded map evidence

Replace free-form graph generation with visible-location inventory, inventory-only completeness audit, connectivity evidence, deterministic graph build, at most one error-scoped patch, and a final image audit. Existing shared durable budget takes precedence (maximum five dispatches per analysis; four without a patch). Never raise a scenario hard block for a map-only failure.

Inventory covers every floor, side elevation, inset and location legend. Validate visible nonempty exact labels and image evidence; normalize duplicates within a section, preserve original labels, distinguish furniture/nonlocations, and derive stable unique IDs in code. Inventory audit returns only newly missing locations and uncertainties, merged deterministically before connectivity. It cannot regenerate inventory or inspect topology.

Connectivity uses original image plus canonical inventory; returns entry evidence, directed edges (from/to, type, compass, visual_basis, evidence), and newly noticed missing locations. Unknown targets/rooms are errors, never silently accepted. Only door/open passage/stairs/explicit one-way evidence supports edges; walls/adjacency/proximity/shared walls do not. Code builds the canonical scene_map and invokes the existing structural validator. Unresolved entry produces an incomplete quarantined map, never an invented entry or scenario hard block.

The single targeted repair returns add_locations/remove_edges/add_edges/replace_edges/entry_update only, constrained to reported errors. It must explicitly recheck original-image evidence for added locations. No room removals or full graph outputs. Preserve all unrelated evidence; changes to verified evidence require fresh image evidence and a reason. Apply patches atomically and deterministically; reject out-of-scope changes, invented unknown rooms/targets, malformed edges and unsupported bases. Final image audit validates all rooms/edges/entry and completeness, preserving inventory locations and prior supported evidence. Incomplete/invalid outcomes never enter gameplay maps.
