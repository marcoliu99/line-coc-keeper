# 首次可遊玩匯入與單調重新解析

首次匯入以可信核心正文可遊玩為目標。UNKNOWN、來源重要性候選與 enhancer 不可用，不是權威，也不是單獨阻止發布的證據。未驗證圖片內容必須在 canonical composition、RAG、索引與 topology extraction 前隔離。核心閱讀順序、安全規則數值、具體證據支持的唯一必要缺失來源，以及無法構成可信可遊玩核心，仍可阻止發布。

僅修改 admission composition 與 deterministic reparse merge；不改 OCR、地圖／憑證、topology、runtime 與遊戲規則。禁止書名／頁碼特例。使用來源 hash、實體頁與區域 identity、來源角色證據，不用 confidence 發布。

已發布版本包含 legacy 均為既有權威。新版未知不得覆蓋；相同已驗證內容保持；不同已驗證內容保留現況並記錄衝突。新增獨立驗證的頁／區域／artifact 才能升級隔離內容。憑證對最終來源重新驗證，不因 merge 改綁；保留既有有效地圖與預製角色。整體 merge 在 library staging transaction 原子提交；失敗不動現版。live correction 保留時間線、角色資源、檢定、戰鬥與位置。

隔離內容與完整證據僅存 private provenance；公開報告只存決策、hash、數量。Reparse diff 保存 old/new/selected authority、保留／升級／衝突／延後與前版 identity。沿用成功／警告／等待／失敗 UX；重新解析回報改善／無改善／衝突，不中斷遊玩。

先加 public extraction/library/command regression，再最小修正。驗證 unknown 隔離、真核心安全、authority 排除、page/region 單調性、feature 添加、衝突、transaction failure、state 保護。執行完整 pytest、ruff、mypy、compileall、diff-check 與 Standards/Spec review。六本 real validation 遵守既有 production cap 與 OpenAI bounded authorization；Haunting 僅已發布版本 reload/start，其他五本 fresh isolated first import，source-safe 才完成 publication/reload/use/start。Production reparse smoke 驗證無 downgrade、無 state reset。未驗證結果標 PENDING，不冒充成功。

取捨：首次匯入可不啟用尚無權威的非核心內容。有具體核心缺失證據時可保留 blocking review；reparse 不用模型偏好或較新版本自動解決權威衝突。
