# 字典裡的 CoC7 譯名表

[English](coc7_glossary_design_spec.md)

狀態：**已實作**。基準：`main_v2` 的 `7dc932c`。

## 問題

自學習字典（`app/dictionary.py`）原本只有約 50 個英文技能名。玩家打簡中或其他常見譯法（侦查、話術、喬裝、估價），或提到神話存在時，都查不到。除了技能之外，也沒有共用的 CoC7 譯名表。

## 改動

- **`app/data/coc7_glossary.json`**：238 個 CoC7 名詞，每條有英文、繁中（`zh_tw`）、簡中（`zh_cn`）、其他常見譯法和出處。涵蓋屬性 15、技能 86、規則用語 38、神話存在 71、典籍與地名 28。
  - 出處都是固定到某個 commit 的社群翻譯：Foundry VTT CoC7（繁、簡）、海豹骰 CoC7 模板、COC不全书、HKTRPG 骰子機器人、Roll20 角色卡、Komica wiki，以及一份 TRPG 角色卡專案。
  - 每條都有 `canonical`，也就是本專案固定使用的名字：
    - **技能：** 用本專案原本的技能名（例如 話術、话术 → 快速交談；喬裝 → 偽裝；鎖匠 → 開鎖），已建立的角色卡不受影響。
    - **其他名詞：** 用繁中名；本專案已有用語的照舊（極難成功，不是極限成功；守密人，不是守祕人）。
  - 只有簡中的兩條補上了直接轉寫的繁中（永久性瘋狂、食屍教典儀）；另有六條標成 `zh_tw_converted`。
- **字典。** 技能條目的每種寫法都經由 `lookup_skill` 對應到標準技能名，也就是檢定和結算行原本就在用的 `skill_aliases.canonical_skill_name`。其他條目放進新的 `terms` 表，用 `lookup_term` 查詢。
  - 單一個字的寫法（斧、劍）不收。
  - 兩個條目都用的寫法不收。
  - 屬性名不會被當成技能。
  - 部署已存的或學到的內容仍然優先；這次改動前存的字典，讀取時也會帶上這些內建譯名。

## 尚待確認

- 來源不一致的，最常見的放第一，其他列為別名。例如極難成功／極限成功、HP 生命值／耐久值、因斯茅斯／印斯茅斯。
- 《Unaussprechlichen Kulten》的「不可名狀的教團」是依字義對應的，需要再確認。
- `terms` 表目前還沒提供給 Keeper，之後可接到 `scenario_names_consistent_design_spec.md` 的劇本名字規則。

## 驗證

`tests/test_coc7_glossary.py`：

- 每條都有標準名和已知出處。
- 技能條目對應到專案的技能名，其他寫法也查得到。
- 單字寫法和屬性名不當成技能。
- 名詞都對應到同一個繁中名。
- 已存的字典保留學到的內容，同時帶上譯名表。
