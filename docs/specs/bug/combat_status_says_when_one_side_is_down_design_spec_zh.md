# 一方全滅時，戰鬥狀態會說明

## 問題

沒有任何東西告訴守密人戰鬥已經結束。在 Haunting 的一次測試中，鼠群已經倒下，而三名調查員也倒地無法行動，但守密人仍然連續好幾個回合推進戰鬥，才想到要預覽結算。守密人在每個戰鬥回合開頭讀到的狀態文字，只列出各戰鬥員。

## 修改

`status_text` 在一方全滅時，於結尾多加一行：每個敵人都倒下時是「敵方已全數倒下，戰鬥可以結算了。」；每名調查員都倒下或離場時是「我方已全數倒下或離場，戰鬥可以結算了。」這行只說明戰鬥可以結算，不會自己結算，也不寫工具名稱，因為玩家也會看到同一份狀態。雙方都還有人站著時不會出現。

## 不做

不會自動結算，也不會拒絕或強制預覽：戰鬥也可能在敵人還站著時結束（逃跑、投降）。守密人的提示本來就寫了戰鬥結束時先預覽再確認。

## 測試

`tests/test_combat_flow.py`：開始時沒有這行；唯一的敵人倒下時出現敵方那行；唯一的調查員離場時出現我方那行。
