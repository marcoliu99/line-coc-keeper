# 昏迷就是倒下、擊殺要說出來、引擎結算的反擊要顯示、防禦的 Luck 只在有用時提供

[English](combat_down_death_counter_luck_design_spec.md)

狀態：**已實作**。基底：`main_v2` `707ad26`。

## 問題

2026-10-11/12 在 707ad26 跑的 soak：

- **昏迷的調查員還在打。** Haunting rerun4：George 第 38 回合重傷 CON 失敗，第 39、43 回合仍然出手。自動擲骰時 `request_injury_check` 只記了昏迷，沒有把戰鬥者標為倒下；只有手動擲骰的路徑會標。
- **敵人死了沒說。** Lightless rerun2 第 56 回合：20 點的一槍打死混血、戰鬥結束，結果行只寫「受到 20 點傷害」，敘事也沒說牠倒下。`_wound_tail` 只看調查員的傷勢紀錄。
- **反擊命中卻沒顯示。** Haunting rerun4 第 42 回合：James 選反擊，引擎擲骰，Corbitt 掉 3 HP；玩家只讀到「已選擇「反擊」。已依系統紀錄處理」。只有「不閃躲」會走顯示這一擊的路徑。
- **提供改變不了結果的 Luck。** Lightless rerun2：6 次防禦擲骰在攻擊本來就打不中、對方擲出極限、或已經躲開時仍問 Luck。

## 改法

- **倒下就是倒下。** 自動擲骰的 CON 失敗，和手動擲骰一樣把戰鬥者標為倒下。
- **擊殺要說。** 傷害紀錄寫明目標倒下、又沒有調查員傷勢時，`_wound_tail` 加上「，倒下了」。
- **引擎結算的選擇要顯示這一擊。** 任何選擇只要結果已完成、玩家沒有要擲的骰，就走 `_settled_without_roll`（⚔️ 那行與守密人敘事），不只「不閃躲」。
- **防禦的 Luck 只在能改變結果時提供。** `dice.useful_defence_luck`：閃避或反擊時，攻擊本來就打不中閃避、沒有等級能勝過、或已經做到時都不提供；其餘只提供達到所需等級以上的選項。玩家擲與自動擲的防禦都套用。其他擲骰照舊提供（Luck 仍是產品決定）。
