# 倒下的不再逼近、過去的事不重演、包裝尾巴剪掉

[English](narrator_continuity_and_junk_tail_design_spec.md)

狀態：**已實作**。基底：`main_v2` `6b59dc5`。

## 問題

2026-10-11 soak 跑出來的三種走樣，全都在玩家看到的文字裡：

- **倒下的敵人還在逼近。** Lightless Beacon fresh5：第 39 回合 Thomas 一槍把幼體打倒；第 44、56 回合玩家還是讀到「幼體與深潛者混血仍在雨幕中逼近」。Narrator 看到的戰鬥狀態裡，幼體那一列寫的是「HP 未公開（倒下）」，不夠明顯。
- **這一擊被安在別的敵人頭上。** 第 39 回合：深潛者混血朝 Mei Lin 揮的那一下，被寫成「幼體的利爪撕向 Dr. Mei Lin」。防禦檢定登記時沒有 `action_context`，已結算檢定區塊顯示「行動情境：未提供」，Narrator 只好猜攻擊者。
- **登島又講了一次，開場又講了一次。** 第 60、61 回合（島上打完後兩次說「我們登上 Beacon Island」）各寫了一次全新的登島；第 93 回合（重述開場前提）從日期開始把開場白整段重寫。
- **包裝尾巴送到玩家眼前。** fresh5 第 1 回合的原文結尾是 `…又為何前往羅克波特？」}} bheidh`，Camp Sunny rerun3 第 57 回合是 `…你要怎麼查看？」}}`：模型把敘事包成 JSON 字串，收尾的括號留了下來。`strip_leaked_decision` 只拿掉決策物件，這不是。

## 改法

- **戰鬥狀態用一行講清楚。** 有敵人倒下、也有敵人還站著時，`combat.status_text` 在各列之後加一行「已倒下、不會再行動：幼體（深海夢魘）。仍在戰鬥的敵人：深潛者混血。」全倒或全站：不變。
- **防禦檢定寫明攻擊者。** 防守方的選擇、以及選完後取代它的閃避／反擊擲骰，登記時都帶 `action_context`「深潛者混血 攻擊 Dr. Mei Lin；這是 Dr. Mei Lin 的防禦」（射擊寫「開槍射向」）；已結算事件由那次擲骰產生，已結算檢定區塊因此會連同骰值一起給 Narrator。
- **Narrator 兩條規則。** 標了（倒下）或列在「已倒下」的敵人不會再逼近、攻擊或行動；這一擊是誰出手的，照已結算檢定寫的攻擊者寫。玩家重述早已發生的事（島上打完又說登島、再講一次開場航程）不重演、不重新開場：一句話帶過，接回現在的地點、時間與剛發生的事。
- **剪掉包裝尾巴。** `presentation.strip_junk_tail` 跟 `strip_leaked_decision` 一起在回覆管線的第一步執行：去掉結尾沒有任何開括號在等它的 `}`／`]`（依位置配對，不是比數量）、它後面的零散英文字、以及沒有對應開引號的收尾引號（」、” 或 "）。前面括號平衡的內容、敘事自己開的引號都保留。

## 不改的

- 戰鬥中的 Luck 提示維持原案（玩家決定）。
- 不事後改寫敘事：狀態行與規則是輸入，文字仍由模型寫。
