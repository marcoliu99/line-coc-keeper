# 回退 PR #91 採買回合實作

狀態：使用者已要求實作。基底：`main_v2`。分支：`revert/pr91`。

## 目標與範圍

回退 PR #91 的採買交易流程、現金帳本指令、購買收據、Executor 購買防護，以及對應工具、提示詞和 Help。PR #106 後續修改了這套流程；必要時移除相依變更，確保程式與測試一致。PR #91 中能獨立解決資訊查詢誤判的回合裁決修正則保留。

## 資料與相容性

不刪除或改寫玩家存檔。過往留下的現金餘額或購買收據可能仍在序列化資料中，但不再授權新交易。不自動退款或回收物品，避免猜測舊行動和價格。

## 流程

```text
含 PR #91、#106 的 main_v2
 -> 反向套用 PR #91 合併提交
 -> 移除 PR #106 專屬的採買相依邏輯
 -> 恢復一致的 Help／工具／提示詞
 -> 測試與隔離的儲存驗證

```

## 驗證與取捨

執行採買與回合相關測試、隔離的完整測試、Ruff、mypy 與差異檢查。更新針對已移除指令與工具的測試，保留獨立的回合裁決測試。此回退會移除原子付款及交易收據。不修改正式遊戲狀態，也不重啟機器人或執行線上遷移。

## 審查修正

首次審查曾恢復回退前以信用評級裁定負擔能力的規則，並將中英文持物文件改述為 `add_carried_item` 登記，移除過時的報價、扣款及收據保證。其中信用評級判斷已被下方使用者後續指示取代。

## 後續範圍調整

使用者接著要求連購買時使用信用評級的判斷一併移除。取得仍須有到店、供應、來源及合法性依據，不以信用評級、生活水準、價格或現金設門檻。角色卡的信用評級技能仍保留供其他遊戲用途。現行指南與參考文件須對齊此規則；舊購買規格維持歷史標記。
