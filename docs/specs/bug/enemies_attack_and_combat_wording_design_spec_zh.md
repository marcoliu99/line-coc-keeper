# 敵人會出手、Narrator 知道這一擊、玩家不再看到結算用語

[English](enemies_attack_and_combat_wording_design_spec.md)

狀態：**已實作**。基底：`main_v2` `4e63718`。

## 問題

2026-10-11 soak：

- **頭目從不出手。** Haunting rerun3：Corbitt 輪了三次，一次防禦都沒開，沒人掉血。Camp Sunny rerun4：Billy 一樣。`_plan_enemy_turn` 只要特殊能力的觸發條件符合就優先選它，而預設觸發每回合都符合；`run_enemy_plan` 沒有這種能力的規則，只敘述、不消耗次數，下一回合又選到同一個能力。
- **敘事和剛結算的攻擊矛盾。** Haunting rerun3，8 個戰鬥回合有 5 個：「你的拳頭尚未揮出」旁邊是「⚔️ 命中，受到 3 點傷害」。Narrator 看到的是推進到下一位之後的戰況，這一擊只藏在原始收據裡。
- **玩家看到結算用語。** 8 則回覆有「【戰鬥暫定；尚未結算】」，13 則擲骰後續有「（戰鬥尚未結算）」，戰鬥擲骰下方有「【戰鬥機械結果暫定；尚未結算】」，連打完最後一擊也有。
- **空槍被拒卻沒說原因。** Lightless rerun3 第 79 回合：玩家讀到「要攻擊的話，請指名上面列出的敵人」，但他已經指名，真正原因是左輪沒子彈。
- **替別的調查員擲的骰被丟掉。** Camp Sunny rerun4 第 62 回合：一位玩家的回合擲了另一位調查員的修理（玩家要求的），驗證時被判成沒有效果，骰子已擲、玩家被要求重講。

## 改法

- **引擎只能敘述的能力只講一次。** 規劃時，同一個敵人這場戰鬥已經「只敘述」過的能力，若它有打得到的攻擊就略過，改成攻擊；沒有攻擊的敵人照舊用能力。自動推進的敵人回合摘要會帶上那段能力敘述。
- **Narrator 收到這一擊的事實。** `build_mechanic_facts_block` 加上「【本回合已結算的攻擊：已經發生】」，列出本回合 `declare_combat_action`／`run_combat_action`／`submit_combat_choice` 的公開攻擊結果行（重播的已轉為內部），並要求先寫這一擊、再交代輪到誰，不可寫成還沒出手。
- **玩家文字不再有結算用語。** `observe_tool` 不再加暫定標記；`finalize` 不再在這一擊後面加「（戰鬥尚未結算）」；戰鬥擲骰行拿掉狀態尾巴（給守密人的訊息保留）。角色卡狀態仍顯示暫定 HP。
- **說出哪把槍沒子彈。** 問話的玩家正好是目前行動者時，戰鬥指引會加上「.38 Revolver 已經沒有子彈，可以改用徒手或其他武器。」（依戰鬥中的工作資源，彈藥為 0 的槍）。
- **本回合擲的骰算數。** `validate_resolution` 把本回合工具擲出的已結算檢定當作這回合的效果，不論是誰的技能。

## 不改的

- 不替劇本特殊能力寫規則；守密人仍可用對應工具套用效果。
- 不比對敘事字句；事實區塊來自工具結果的結構。

## 驗證

`tests/test_enemies_attack_and_combat_wording.py`：講一次後改攻擊；沒有攻擊仍用能力；攻擊事實區塊，以及重播、拒絕、其他工具時沒有；HP 與攻擊行沒有結算用語；只有彈藥 0 時才說沒子彈。更新：`tests/test_combat_turn_friction.py`、`tests/test_combat_wiring.py`、`tests/test_turn_consistency_handoff.py`。
