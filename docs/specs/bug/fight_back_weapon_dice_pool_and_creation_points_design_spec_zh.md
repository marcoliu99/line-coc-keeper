# 三個規則錯誤：反擊不看武器、加骰可能骰出 100、建角技能點是規則的 5 倍

[English](fight_back_weapon_dice_pool_and_creation_points_design_spec.md)

狀態：**已實作**。基準：`main_v2` 的 `25b6d13`。

## 問題

2026-10-11 的 main_v2 code review 找到三處引擎偏離 CoC 7e、玩家會有感的地方。

1. **反擊不看手上的武器。** 防禦選項裡的反擊永遠是格鬥（鬥毆），傷害固定 `1d3`：`counter_damage` 有宣告在行動紀錄上，卻沒有任何地方設定。拿斧頭的調查員只能空手反擊。
2. **加骰可能把 30 變成 100。** `roll_percentile_with_dice_pool` 只比十位數。個位 0 時，十位 0 其實是 100（最差的骰），但它是最小的數字，所以加骰會選到它；懲罰骰選最大的數字，反而讓玩家躲過 100。
3. **`/coc create` 給 EDU×20 職業點、INT×10 興趣點。** 規則書是 EDU×4、INT×2。配上 90% 上限，自建角色幾乎能把每個技能點滿。

## 變更

- **反擊用手上的武器。** 反擊選項帶著武器的技能、數值、傷害與 DB 規則。「手上的武器」依序是：防守方這場戰鬥自己上一次近戰攻擊用的武器；否則身上攜帶的近戰武器中技能最高的那把（武器欄與攜帶物品都對照武器表）；否則空手，1d3 + DB，跟以前一樣。選項標籤會寫出武器（「反擊（小刀）」），按鈕和門檻提示都會說玩家揮的是什麼；打字輸入「反擊」一樣能選到。收據會記下武器（`counter_weapon`）。極難反擊仍是普通傷害，不變。
- **加骰／懲罰骰比較完整的骰值。** 每顆十位骰都和個位骰組成它會變成的骰值（00 → 100）；加骰留最低的，懲罰骰留最高的。
- **建角點數照規則書：** EDU×4、INT×2。

## 不變更

- 「手上的武器」是推斷的，不是追蹤的；玩家想換武器可以直接說，由守密人裁定。
- 職業點仍可點在任何技能上，也不要求信用評級；這兩項交給守密人把關。

## 驗證

- `tests/test_combat_flow.py`：帶著小刀的防守方會看到「反擊（小刀）」、用格鬥（鬥毆）、反擊傷害 1d4；上一次攻擊用的武器優先於技能更高的攜帶武器；沒有武器就是反擊 1d3。
- `tests/test_dice_pool_and_creation_points.py`：個位 0、十位 3/0 時加骰得 30、懲罰骰得 100，一般骰不變；EDU 60 / INT 60 的新角色得到 240 職業點與 120 興趣點。
