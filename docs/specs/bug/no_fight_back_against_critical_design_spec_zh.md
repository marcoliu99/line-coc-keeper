# 大成功攻擊下，防守方不再有「反擊」選項

[English](no_fight_back_against_critical_design_spec.md) | [文件索引](../../README.md)

類別：`bug`。狀態：**已實作**。基準：`main_v2` 的 `961c9ce`。

## 問題

敵人的近戰攻擊擲出大成功時，防守方不管擲出什麼成功等級都贏不過它，所以「反擊」只會輸（見[閃避、反擊與遠程規則](bug-dodge-counter-tie-and-ranged-mechanics_zh.md)）。較舊的 NPC 攻擊工具會在這個情況拿掉「反擊」選項，但 managed 戰鬥自己的防守選擇從來沒有，所以玩家面對大成功攻擊時，仍然被給了一個一定會失敗的「反擊」，選了就白白浪費一個回合。

## 修改

`app/combat_flow.py`（`_defense_choice`）：近戰攻擊的攻擊骰是大成功時，防守選擇只給「閃避」。其他攻擊維持「閃避」和「反擊」；遠程攻擊（閃躲或不閃躲）不變。

## 不做

不改閃避或反擊的結算方式，也不改 Discord 的提示（它對無法顯示門檻的「反擊」本來就會略過說明行）。

## 測試

`tests/test_combat_engine.py`：大成功攻擊（骰出 1）只給「閃避」，並能一路結算到命中；一般攻擊仍然給「閃避」和「反擊」。
