# 戰後 HP 0 就是倒下、昏迷的調查員不會被一直擋在遊戲外

[English](down_investigators_wake_design_spec.md)

狀態：**已實作**。基底：`main_v2` `b0c11f3`。

## 問題

來自 b0c11f3 的 2026-10-12 Haunting soak：

- **HP 0 照常行動。** Edith 戰鬥結束時 HP 0，之後又行動了 11 回合、擲了三次外貌檢定。7e 規定 HP 0 是昏迷，有重傷則是瀕死。`knocked_out` 要求 HP 大於 0，所以她從沒被擋下。
- **昏迷等於被鎖住。** James 在 HP 1 時重傷體質檢定失敗。因為隊友都還站著，他每句話都只得到「隊友可以替James急救」；沒人急救，他的玩家枯坐了 44 回合（11 句話）。

## 改動

- **HP 0 就是倒下。** `unconscious_wake.knocked_out` 在戰鬥外也涵蓋 HP 0 與瀕死；已死亡不算。
- **瀕死的人等急救。** 傷勢標為瀕死，或傷勢沒另外註明時 HP 0 且有重傷（已穩定的人是 `dying=False`），每句話都等急救，回覆「…倒地瀕死…隊友要盡快替…急救」。是否活下來交給戰後義務處理。
- **提醒一次，之後就醒。** 其他倒下的調查員在有隊友站著時，只收到一次急救提示，同時告訴玩家：沒人急救的話，下一次行動會在一段時間後自己醒來。提示記在狀態的後果記錄裡，以角色為鍵，連同當時的 HP 與傷勢（不放在傷勢欄位，戰鬥引擎會驗證那裡的欄位）；同一次倒下的下一句就走既有的時間跳躍甦醒，先前那次倒下的提示不算。沒有人站著時，第一句就醒，與原本相同。
- **從 HP 0 醒來** HP 變成 1，重傷仍在；醒來時清掉提示記錄。

## 驗證

`tests/test_unconscious_wake.py`：
- 戰後 HP 0 算倒下，醒來 HP 1；
- 瀕死者每次都等；
- 提醒一次後，下一句就醒，醒來時清掉提示；
- 等待回覆含甦醒說明並記下提示；
- 戰鬥中或已死亡不適用。
