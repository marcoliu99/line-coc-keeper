# 戰鬥中被拒絕的行動，說明現在輪到誰

## 問題

玩家在戰鬥中的行動無法進行時，桌上看到的是「劇本裡沒有足夠的內容可以據以裁決這個行動」或「這個行動無法進行」，後面接著已經出現過的人物與地點（「人物：鼠群」）。這是探索時用的說法。在 Haunting 的戰鬥裡，真正的原因多半是還沒輪到這位玩家，或敵人已經全倒、戰鬥正等著結算，玩家卻被引導去找東西問。

## 修改

對措辭會談到劇本的三種原因（`no_scenario_evidence`、`executor_no_action`、`unsupported_action`），進行中的戰鬥改用 `turn_fallback.combat_guidance`，並且不附場景提示：

* 戰鬥已進入結算階段：說明戰鬥已結束，正等守密人結算；
* 敵人已全數倒下：同樣說明正等結算；
* 其他情況：說明現在輪到誰（「現在輪到「X」行動」），並請玩家輪到自己時說明要對哪個目標、用什麼方式行動，還沒輪到就稍候。

其他原因，以及不在戰鬥中的回合，措辭不變。

## 不做

原因的判斷與重試都不變，只改桌上讀到的文字。

## 測試

`tests/test_turn_fallback.py`：三種戰鬥情況、戰鬥不再進行時恢復原本的措辭、其他原因不給戰鬥說明。
