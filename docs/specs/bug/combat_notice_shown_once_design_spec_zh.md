# 同一句戰鬥提示只顯示一次

## 問題

一個回合每呼叫一個戰鬥工具，就會留下一行公開文字「戰鬥機制操作已記錄；後續以目前戰鬥狀態為準。」在 Haunting 的一次測試裡，玩家連續看到同一句三次（第 29、45 輪），第 51 輪看到四次。如果其中有些呼叫帶了「【戰鬥暫定；尚未結算】」的標記、有些沒有，這幾行也不完全相同，單純比對整行去重會把它們都留下來。

## 修改

新增 `turn_delivery.distinct_lines`：同一行只說一次，有標記和沒標記的同一行視為同一行，留下有標記的版本。凡是把一回合的結果行交給玩家看的地方都用它：回合未完成時的提示（`prompt_config.enforce_mechanic_check_consistency`）與交付信封的投影文字。

## 不做

提示的措辭與回合其他要顯示的內容都不變。

## 測試

`tests/test_turn_fallback.py`：三筆相同提示、其中一筆帶暫定標記，只顯示一次並保留標記。
