# 一次呼叫替每位目擊者擲理智、反引號裡的擲骰指令也算數、已結算那行說出擲了什麼

[English](sanity_witnesses_told_skill_design_spec.md)

狀態：**已實作**。基底：`main_v2` `707ad26`。

## 問題

來自 707ad26 的 2026-10-12 soak：

- **只有行動者失去理智。** 三個劇本都一樣：prompt 已寫「在場目擊的每一位調查員各擲一次」，守密人還是只替行動的玩家呼叫一次 `sanity_check`；其他人看見同樣的恐怖景象卻沒有損失。
- **擲骰提示又重複了。** #278 會在回覆已經給了指令時拿掉「請使用檢定按鈕或 /coc check」，但寫成程式碼樣式 `` `/coc check` `` 時不算數，33 則回覆出現兩次。
- **Luck 之後看不出擲的是什麼。** 已結算那行只寫「已結算檢定：骰值 52，結果為「一般成功」」，沒有調查員也沒有技能；而 Luck 決定之後，玩家讀到的就只有這一行。

## 改動

- **`sanity_check` 接受 `witnesses`。** 可選，列出其他看見同一景象的調查員。工具閘道把它拆成每人一次普通的 `sanity_check`：各自擲骰或登記、記錄與告知，都跟模型自己逐一呼叫完全相同；名字等於主要調查員或已擲過的就略過。守密人拿到的結果以第一筆真的擲了的為主（主要調查員因已有待處理檢定被拒時，不會蓋掉其他已擲的目擊者），其餘結果（包括被拒的）放在 `witnesses` 清單。Prompt 與數值表提示改成一次呼叫帶名單。誰看見了仍由守密人判斷，不做視線偵測。
- **反引號也算指令結束。** `InteractionRef.told_in` 接受 `/coc check` 後面的 `` ` ``。
- **已結算那行說出擲了什麼。** 「已結算檢定：Marco 的偵查，骰值 52，結果為「一般成功」。」，取自已結算檢定本身的 `investigator` 與 `skill`。
