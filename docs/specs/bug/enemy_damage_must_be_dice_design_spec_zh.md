# 敵人的傷害必須是骰子表示式

## 問題

在 Haunting 的一次測試中，守密人把飛刀的 `damage` 填成「`1D4+2；極限成功 6+1D4+2`」，是從劇本整句抄來的。戰鬥接受了它。第一次攻擊時引擎解析不了，戰鬥停在 `NEEDS_RULING`，玩家無法繼續。

## 修改

加入敵人時，每個攻擊的 `damage` 會用引擎擲骰用的同一套骰子語法檢查。不是骰子表示式的字串，在碰到戰鬥之前就被拒絕，並說明怎麼改：`damage` 只填骰子；極限成功的差異用 `source.extreme_rule`（`maximum`，穿刺類武器填 `impale`）。守密人修正後再呼叫一次；同一次呼叫裡的其他敵人照常加入。

載入已存的戰鬥時不檢查。

## 不做

不猜測自由文字裡哪一段是骰子，也不自動選 `extreme_rule`。

## 測試

`tests/test_combat_wiring.py`（公開的初始化工具拒絕它、不改變狀態、接受修正後的條目）與 `tests/test_combat_engine.py`（被拒絕的條目不會讓沒有戰鬥的對話開戰）。
